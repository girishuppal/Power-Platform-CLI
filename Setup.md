# What is PAC CLI?
##### Power Platform CLI is a unified developer tool that empowers developers, administrators, and independent software vendors (ISVs) to manage the entire lifecycle of Microsoft Power Platform components


# Power Platform CLI Setup

#### Three ways to setup Power Platform CLI

1. Install through VS Code https://learn.microsoft.com/en-us/power-platform/developer/howto/install-vs-code-extension
2. Install with .net tool https://learn.microsoft.com/en-us/power-platform/developer/howto/install-cli-net-tool?tabs=windows
3. Install with Windows MSI https://learn.microsoft.com/en-us/power-platform/developer/howto/install-cli-msi
