# PAC PACKAGE
---

`pac package init` <br/>
Creates a package project

`pac package init --outputDirectory ./GiriPackage --package-name GirishPackWell --publisher Girish` <br/>
Creates a package project with package name and Publisher

`pac package add-solution --path 'C:\GIRISH\CODE\PAC CLI\gamma\RocketSolution.zip'` <br/>
Adds solution reference to a package solution
