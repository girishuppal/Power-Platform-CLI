`pac copilot list`
Lists all the agent within the environment

 `pac copilot init --name GiriSep122026Agent --publisher-prefix gir`
 Create Copilot source code file in the folder

 `pac copilot clone --bot f1a3aa4c-7b7c-f011-b4cc-000d3ad1e145`
 Clones the copilot into local directory

`pac copilot delete --bot 473d3b4a-7067-4a60-87a9-b942b9ae0a4c --confirm`
Deletes the Copilot


`pac copilot push`
Pushes Copilot Studio changes to local repository

`pac copilot pull`
Push local changes from workspace to Copilot Studio

`pac copilot publish --bot f1a3aa4c-7b7c-f011-b4cc-000d3ad1e145`
Publishes the agent

 `pac copilot pack --publisher-prefix gir`
Creates Solution zip file for an agent

`pac copilot model list`
Lists all AI models that are available for use

 `pac copilot quarantine --bot-id f1a3aa4c-7b7c-f011-b4cc-000d3ad1e145`
 Gets quarantine status for an agent

 `pac copilot extract-translation --bot ee663f41-736d-43fb-a676-c1bb1349eb72`
 Extract translation details for an agent
